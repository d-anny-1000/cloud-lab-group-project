About the Project

Building a clean responsive website for our course assignment

This website was created as a group assignment for the Cloud Computing course. Our goal is to present our group, show our understanding of static web design, and build a clean responsive website using HTML, CSS, and JavaScript.

What the site includes

Clear information with simple navigation

The site includes a home page, an about page, and a contact page. Each page uses the same layout so visitors can move easily between sections and quickly understand the purpose of the group project.

The project is prepared as a static website, making it suitable for GitHub Pages deployment.
